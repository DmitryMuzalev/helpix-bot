# Helpix Bot

This project is under development.

Helpix Bot is an application for collecting technical support requests through Telegram. The bot receives client messages and saves conversation history.

The web interface lets you view clients and their requests, search for conversations, and maintain a knowledge base with guides and solutions.
New messages appear automatically.

Supabase provides data storage, authentication, and backend logic.

[Web interface](https://helpix-bot.vercel.app/)

[Telegram bot](https://t.me/helpix_helpdesk_bot)
